📘 College Assessment & Methodology Statement

Optimization Methodology: This system applies deterministic rule-based heuristics developed in accordance with the AWS Well-Architected Framework (Cost Optimization Pillar). It evaluates service spend proportions, identifies top cost drivers, and suggests targeted actions.

Academic Clarification: This project does not employ a black-box machine learning model or neural network. Heuristic rules are fully auditable, reproducible, and transparent. Detailed instance-level rightsizing requires detailed CloudWatch agent metrics and human review before making resource changes.
